# Project Overview
Saif Trading Co V1 is a premium rough gemstone catalogue + business website + secure admin management system.

Visitor: Search → Home → Collections → Gemstone → Inquiry/WhatsApp.
Admin: Login → Dashboard → Gemstones → Add/Edit → Publish/Update/Sold.
Priorities: Trust, product presentation, discoverability, usability, SEO, performance, maintainability.
